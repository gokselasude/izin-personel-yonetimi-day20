# İzin ve Personel Yönetim Sistemi - Final Teslimi

Bu proje, personel yönetimi ve izin taleplerinin takip edildiği full-stack bir uygulamadır.

## Kurulum ve Çalıştırma
1. Repoyu klonlayın: git clone https://github.com/gokselasude/izin-personel-yonetimi-final.git
2. Ana dizinde terminali açıp şu komutu çalıştırın: docker compose up -d

## Bağlantı ve Bilgiler
* Frontend Adresi: http://localhost:4200
* Backend API Adresi: http://localhost:8080
* Swagger Dokümantasyonu: http://localhost:8080/swagger-ui.html
* Varsayılan Admin Kullanıcısı: admin / 123456
